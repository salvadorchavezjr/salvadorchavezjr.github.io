# Salvador Chavez Jr. | IT Portfolio

Welcome to my personal IT portfolio! This website highlights my professional background, technical skills, and hands-on projects as I transition from the United States Navy into the information technology industry.

**[GitHub Profile](https://github.com/salvadorchavezjr) | [LinkedIn Profile](https://www.linkedin.com/in/salvador-chavezjr/)**

## About This Project

I developed this website as part of my Microsoft Software & Systems Academy (MSSA) Server & Cloud Administration project week.

The goal was to build a professional online portfolio where I could showcase my technical projects, share my background, and demonstrate my growing skills in web development and version control.

The website was built from scratch using HTML, CSS, and JavaScript in Visual Studio Code.

## Website Features

- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Modern Light Theme:** Clean white backgrounds, navy typography, and blue accents.
- **About Me:** Introduces my military background and transition into IT.
- **Technical Skills:** Highlights my experience with Windows Server, PowerShell, networking, and cloud technologies.
- **Projects Section:** Showcases my hands-on PowerShell projects with direct links to their GitHub repositories.
- **Professional Networking:** Provides links to my LinkedIn and GitHub profiles.
- **Interactive Navigation:** Allows visitors to move easily between sections of the website.

## Technologies Used

- **HTML5:** Website structure and content.
- **CSS3:** Styling, responsive layouts, and visual design.
- **JavaScript:** Dynamic copyright year and navigation effects.
- **Visual Studio Code:** Development environment.
- **Git:** Source control and version tracking.

## Featured Projects

### 1. PowerShell System Health Checker

A PowerShell monitoring tool that retrieves Windows system information, monitors CPU and memory usage, checks disk space and service status, and generates CSV reports.

[View Repository](https://github.com/salvadorchavezjr/powershell-system-health-checker)

### 2. Network Troubleshooting Toolkit

An interactive PowerShell application used to diagnose network problems, check IP configurations, test connectivity, resolve DNS records, and check TCP ports.

[View Repository](https://github.com/salvadorchavezjr/powershell-network-toolkit)

### 3. Windows Event Log Analyzer

A PowerShell tool for retrieving Windows event logs, identifying errors and warnings, searching Event IDs, and generating troubleshooting reports.

[View Repository](https://github.com/salvadorchavezjr/powershell-event-log-analyzer)

### 4. Windows Performance Optimizer

A Windows diagnostics and maintenance utility that monitors system resources, identifies resource-intensive processes, analyzes disk storage, inventories startup applications, and offers controlled temporary file cleanup.

[View Repository](https://github.com/salvadorchavezjr/powershell-performance-optimizer)

## Running the Website Locally

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Navigate through the website to explore the different sections.

No additional frameworks, packages, or external dependencies are required.
